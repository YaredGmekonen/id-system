# Silicon Labs Logo Variant Package

This package contains the supplied Silicon Labs logo prepared for common digital, social, presentation, and print placements. The variants preserve the original emblem and the `SILICONLABS` wordmark while providing horizontal, stacked, symbol-only, color, black, white-reverse, and social-avatar options.

All logo artwork files other than the social-avatar files use a transparent PNG background. The social-avatar files intentionally include a dark charcoal background. For best consistency, use the horizontal lockup when the available space is wide, the stacked lockup when the space is square or narrow, and the symbol-only mark whenever the wordmark would become too small to read.

## Basic usage rules

Keep clear space around the logo and do not stretch, rotate, recolor, outline, add effects to, or rebuild the mark. Use the black versions when color reproduction is unavailable, and use the white-reverse versions only on sufficiently dark backgrounds with strong contrast. At very small sizes, use a symbol-only file rather than shrinking the full wordmark lockup.

## File format note

The delivered assets are transparent PNG files suitable for immediate digital use and raster print placement. For professional offset printing, laser cutting, large-format signage, or editable brand-system work, a vector master such as SVG, EPS, or PDF should be created from the approved logo artwork before production.
